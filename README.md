# Openhanako-handwriting ✎

手写稿生成器 — Hanako 插件，将文本渲染为手写风格图片。

## 功能

- **5 款手写字体**：马善政（中文）、清松手写体9 · 文青（中文）、851远星夜行手写体（中文/日文）、Caveat（英文）、Zen Maru Gothic（日文）
- **中英分离设置**：中文、英文、日文/其他各指定不同字体，自动匹配
- **4 种纸张样式**：横线纸、方格纸、信纸、空白纸 × 4 种颜色（米黄/白/浅粉/浅蓝）
- **手写抖动**：无/轻微/明显，模拟真实手写起伏
- **错别字涂改**：`{错→正}` 语法标记，支持单划线/双划线/波浪线/圈出/斜线叉，位置可选上方或行内
- **角色预设**：动态读取 Hanako 助手列表，每个助手分配不同字体/纸张组合
- **贴纸装饰**：12 种 emoji 贴纸，可拖拽位置，可调节大小
- **墨迹效果**：模拟墨水渗透纸面的质感（无/轻微/浓厚）
- **偏好保存**：关闭后自动恢复上次配置

## 安装

1. 将插件目录放入 Hanako 插件路径
2. 在 Hanako 界面中打开 ✎ 图标进入工作台
